# Итоговое домашнее задание: Многопоточный краулер контактных данных (Вариант 1)

## Описание
Приложение для автоматизированного многопоточного сбора контактных данных (Email, телефоны) с веб-сайтов. Реализует современные практики конкурентного программирования на Java.

## Стек технологий
- **Java 21**, **Spring Boot 4.0.8**
- **Spring Data JPA** + **H2 Database** (встроенная in-memory база)
- **Spring WebFlux** (`WebClient` для асинхронных HTTP-запросов)
- **Jsoup** (парсинг HTML)
- **Lombok**

## Реализованные требования по многопоточности (Критерии оценки)

### 1. Кастомный ExecutorService
- В классе `ThreadPoolConfig` настроен `ThreadPoolExecutor` с именованными потоками, ограниченной очередью `LinkedBlockingQueue` (защита от OOM) и политикой `CallerRunsPolicy`.

### 2. Потокобезопасные структуры
- В `CrawlerService` используется `ConcurrentHashMap.newKeySet()` для хранения посещенных URL, что гарантирует защиту от зацикливания и дублирования задач.
- Используется `Semaphore` для ограничения количества одновременных запросов.

### 3. @Scheduled
- В классе `ScheduledTasks` реализован фоновый метод, логирующий состояние системы каждые 60 секунд.

### 4. parallelStream API
- В `CrawlerController` (эндпоинт `/api/answer`) используется `parallelStream()` для параллельной фильтрации и сортировки результатов, полученных из H2, с применением пагинации.

### 5. Межсервисное взаимодействие
- Используется `WebClient` (из `spring-boot-starter-webflux`) с таймаутом для HTTP-запросов.

##  Инструкция по запуску и проверке (для преподавателя)

### 1. Запуск приложения
1. Откройте проект в IntelliJ IDEA
2. Дождитесь загрузки зависимостей Maven
3. Запустите главный класс `CrawlerApplication.java` (зеленая кнопка Play ▶)
4. Приложение запустится на порту 8080
5. В консоли каждую минуту будет появляться сообщение от `@Scheduled`:  
   `[SCHEDULED] Краулер активен. Проверка состояния системы...`

### 2. Тестирование работы краулера (Гарантированный сценарий)
Чтобы убедиться, что парсинг, сохранение в БД и многопоточность работают корректно, используйте встроенную тестовую страницу приложения.
